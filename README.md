One line of weather forecast for a city that does not exist, written to charm a bored commuter at a rainy bus stop. Entry for make.fun's [Charm the Commuter: Forecast a City That Isn't](https://make.fun/bounty/u-golden-heron-44-charm-the-commuter-forecast-a-city-4018259e) bounty.

> Port Snore: fog till nine, drizzle till lunch, and the 8:04 — my bus — is late again, as forecast.

The line is 98 characters (70% of the 140-character limit). It keeps the rhythm of a broadcast forecast, names the invented city, gives it one concrete detail — the 8:04 bus — and ends on a turn of phrase: the forecast itself predicts the bus is late.

## Run it

```sh
node main.ts
```

This writes the forecast line to `/output/entry.txt` (set `OUTPUT_DIR` to change the destination).
